# Shared preprocessing

Settings live in `src/agentic_gan/utils/datasets.json`: input file, target, categorical columns, imputation method, Bank duration option, and split ratios/seed.

```bash
uv run python -m agentic_gan.tools.preprocessing --dataset bank_marketing
uv run python -m agentic_gan.tools.preprocessing --dataset default
uv run python -m agentic_gan.tools.preprocessing --dataset polish
```

Each command writes only `train_cleaned.csv`, `validation_cleaned.csv`, and `test_cleaned.csv` to `data/interim/<dataset>/`. The tables are cleaned and imputed, without encoding or scaling. Exclude `source_row` from model/GAN features. Rerunning replaces these tables and removes artifacts generated by older versions.

Splits are stratified 60/20/20 with seed 42. Keep input rows/order, configuration, and software versions fixed to reproduce them. Missing numeric values use the training median (configurable to mean); entirely missing numeric columns use zero. Categorical gaps use the training mode, with an all-missing fallback category. Validation and test use the training fill values.

- **Bank:** rename the day column to `day_of_month`, preserve/fill `unknown` categories, retain `pdays=-1`, add `previously_contacted`, and exclude `duration` by default. Map the target to 0/1.
- **Default:** drop ID, standardize target and repayment column names, and preserve undocumented codes as separate categories. The current data has no missing values.
- **Polish:** combine all five ARFF cohorts in configured order, retain the cohort label, replace infinite values with missing values, and impute financial ratios. Finite extreme values remain unchanged.

Both baseline arms read raw data and fit imputation, encoding, and scaling in memory within each CV training fold, including stacking inner folds. Final fitting learns preprocessing from training rows only. The three cleaned CSVs are for GAN use; baselines do not read them. Future synthetic-data training should reuse its real-training-fitted transformations without refitting on synthetic rows.

Overrides: `--config /path/to/datasets.json`, `--input /path/to/source`, `--imputation mean`, and `--include-duration`. Input paths in configuration are relative to the repository root; `--root` overrides that root.

```python
from agentic_gan.tools.preprocessing import run_preprocessing

output = run_preprocessing("bank_marketing")
```

The `Preprocessor`, `profile_dataframe`, and `write_treatment_log` functions remain available to agent code for explicit use. The preprocessing command saves only the three cleaned tables. Fraud preprocessing is deferred.
